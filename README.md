# 🤝 SPA - Mãos que Transformam

Uma aplicação web progressiva, responsiva e acessível (SPA) desenvolvida para a ONG **Mãos que Transformam**, focada na captação de voluntários e divulgação de iniciativas sociais.

## 🔗 Link do Projeto
Clique aqui para acessar o site: [Mãos que Transformam](https://joao-igrjj.github.io/projeto-ong/)

## 🚀 Tecnologias Utilizadas
- **HTML5 Semantic & Templates (`<template>`)**: Renderização dinâmica de páginas e componentes.
- **CSS3 Custom Properties & Responsive Grid/Flexbox**: Layout modular e adaptável para dispositivos móveis e desktop.
- **JavaScript ES6+ (Módulos & Hash Router)**: Arquitetura SPA sem recarregamento de página.
- **Day.js (via CDN)**: Formatação de datas relativas ("há x minutos").
- **LocalStorage API**: Persistência de rascunhos de formulários e cadastros de voluntários.

## ♿ Acessibilidade e Boas Práticas (WCAG 2.1 AA)
- Suporte total à navegação por teclado (`Tab`, `Enter`, `Escape`).
- Atributos dinâmicos de acessibilidade (`aria-expanded`, `aria-describedby`, `aria-live`, `aria-current`).
- Contraste de cores validado para legibilidade contínua.
- Mensagens de erro e sucesso em formulários anunciadas por leitores de tela.

## 📁 Estrutura de Arquivos
- `index.html`: Shell da SPA contendo a estrutura base e modelos `<template>`.
- `CSS/style.css`: Estilização global, temas, grid e componentes responsivos.
- `js/`: Módulos JavaScript encarregados das rotas, validações, formulários e persistência.
